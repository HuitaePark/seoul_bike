# 계획 검토 화면 (역할 5)

MapLibre GL JS 6.15.0·OpenFreeMap 배경지도와 트럭 방문 순서·계획 검토 화면이다. Vue 공통 API 클라이언트,
인증, 생성 타입, 작업 SSE를 그대로 사용한다. `src/shared`, 다른 담당자의 작업 콘솔·승인 카드는 변경하지 않는다.

## 확인하기

`frontend/`에서 `npm ci` 후 `npm run dev`로 실행한다.

- `http://localhost:5173/plans/review/demo`: 로그인 없이 가상 자료로 탐색·거점 제외·새 후보 검토·승인·거절.
  업무 API를 호출하지 않으며 새로고침·초기화 시 복구된다. 배경지도는 외부 OpenFreeMap에서 읽는다.
  위치·관측·예측·방문 순서는 가상 자료다. 재계산도 시연용 자료 변환이고 OR-Tools 결과가 아니다.
- `http://localhost:5173/plans/review`: 관리자·책임자용 실제 조회. 근무조 ID를 입력한다.
  `?regionId=권역&shiftId=근무조`로 조회 조건을 전달할 수도 있다.
  실제 조회 실패를 시연 자료로 대체하지 않는다. 현재 기준 backend의 대여소·계획 API는 계약 단계이므로
  실제 서버와의 전체 통합 완료를 뜻하지 않는다.

## 화면 동작

지도는 대여소 위험·미처리·제외 선택과 선택 트럭의 방문 번호를 표시한다. 트럭을 바꾸면
방문 번호·색상·연결선·경로표를 함께 갱신하며, 마커·방문 목록·경로표의 선택을 상세 패널과 동기화한다.
마커는 키보드로 선택할 수 있다. 이름·ID·위험·역할 필터는 지도 마커와 현황 표에서 공유한다.
계획이 아직 없어도 현황 좌표가 있으면 지도를 표시한다. 트럭 실시간 위치는 표시하지 않는다.

점선은 정류장을 seq 순서대로 연결한 **방문 순서 안내**이며 실제 도로 경로가 아니다.
좌표가 없거나 유효하지 않은 거점은 표시하지 않고, 중간 좌표가 없는 연결도 건너 이어 그리지 않는다.
제외 선택은 표시만 바꾸며 새 후보 수신 전까지 원래 계획·연결선을 유지한다.
배경지도 실패 시 마커·연결선과 재시도, WebGL 미지원 시 기존 표·상세·승인 흐름을 제공한다.

기본 스타일은 `https://tiles.openfreemap.org/styles/liberty`다. 지도·데이터 출처를 화면에 표시한다.
팀의 다른 공급자를 쓸 때는 빌드 시 `VITE_PLAN_MAP_STYLE_URL`을 HTTP(S) 스타일 URL로 지정할 수 있다.
지도 타일·글꼴·스프라이트에는 외부 네트워크가 필요하다. MapLibre 엔진은 지도에서 지연 로딩하며
worker는 Vite가 별도 자산으로 묶어 같은 출처에서 제공한다. [공식 연결 안내](https://openfreemap.org/quick_start/).

트럭 선택, 방문 순서·회수/배치·ETA·작업 후 적재량, 빈 경로, 대여소 상세,
우선순위순 미처리 사유와 권역 대여소 검색·위험/역할 필터를 제공한다.
시각은 한국 시간으로 표시한다. 용량·초기 적재·예측 등 선택 필드를 임의의 기본값으로 채우지 않는다.
예측 재고 0과 음수도 보존한다. 예상 빈 대여소 시각·적용 제약은 현재 API가 제공하지 않아 `미제공`이다.

관리자는 작업 콘솔의 계획 승인 작업 UUID를 연결한다. 동일 근무조·계획 ID의 `SUBMIT_PLAN/MANAGER`
승인 카드와 `WAITING_APPROVAL` 상태일 때만 결정을 표시한다. backend가 최종 권한·업무 상태를 판단한다.
책임자는 조회 전용이고 기사에게는 전체 계획을 요청하지 않는다.

대기 거점만 제외 선택할 수 있다. `APPROVE + excludeStationIds`는 새 후보 요청이며,
새 버전·승인 카드가 오면 제외 선택·의견·검토 확인을 초기화한다. 새 안을 다시 확인해야 최종 승인할 수 있다.
최종 승인은 검토 확인이 필요하다. 거절도 동일 승인 API를 쓴다. 202 수신만으로 로컬 계획을 활성화하지 않고,
계획·작업 재조회와 SSE 이벤트에 따라 표시한다. 전송 응답 유실·409에서 같은 결정을 자동 재전송하지 않는다.

조회 변경·모드 전환·화면 종료 때 이전 요청을 취소하고 늦은 응답을 무시한다.
계획·현황을 각각 처리해 현황만 실패해도 계획을 볼 수 있다. 404·403·401·서버 실패·재조회 상태를 제공한다.

## 검증

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

단위 검사는 Node 22 이상, 브라우저 검사는 Chromium을 쓴다. Linux 최초 설치는
`npx playwright install --with-deps chromium`이 필요할 수 있다. E2E는 127.0.0.1:5185에서
전용 개발 서버를 실행하고 공개 API를 가로채므로 backend·실제 계정·지도 키가 필요 없다.
실제 WebGL 엔진·worker를 쓰되 배경지도 스타일은 로컬 응답으로 대체해 CI가 외부 서비스에 의존하지 않는다.
실제 OpenFreeMap 연결은 별도 시각 점검으로 확인한다. 테스트용 로그인 자료는 브라우저 안에서만 사용한다.
실행 보고서·스크린샷은 Git에 넣지 않는다.

## 연결 대기

OSRM 실제 도로 경로선과 실제 backend의 대여소/계획 조회·제외 후 재계산·승인 통합은 후속이다.
기사의 경로 변경 수락, 공통 승인 카드·근거 문서 패널, 작업 생성은 각 담당 화면을 사용한다.
공개 API 밖의 업무 규칙·최적화 계산을 화면에 구현하지 않는다.

필드와 호출 대응은 [화면 명세](../../../../docs/specs/plan-review.md)를 따른다.
