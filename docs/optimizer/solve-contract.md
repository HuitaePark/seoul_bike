# solve 명세 안내

외부 요청·결과는 [공통 AsyncAPI](../specs/asyncapi.yaml)를 따른다.
역할 5의 구현 명세는 [docs/specs/optimizer.md](../specs/optimizer.md)에 있다.

기존 독자 snake_case 요청 예시는 공통 전송 형식과 혼동되지 않도록 제거했다.
공통 요청·결과와 호출 설정 예시는 [examples/optimizer](../specs/examples/optimizer/)를 사용한다.
필드 대응·차량 배정 제한·결과 상태·현재 미구현 범위는 역할 명세를 따른다.
