# 서울시 공지: 2025 서울세계불꽃축제 공유자전거 대여·반납 중단

> 저장소 PRD에서 이 행사를 어떻게 다루는지를 **기본**으로 적고, 서울시 보도자료의 세부 사항을 `[보조]`로 덧붙였다.
> 이 문서는 2025년 행사 기록이다. 다른 해 행사에 그대로 쓰지 말고 그해 공지를 따로 확인한다.

## 1. 우리 프로젝트에서 이 행사의 의미

- 2025년 9월 27일(토) 서울세계불꽃축제 당일, 해당 구역의 따릉이 대여·반납이 일시 중지됐다.
- 역산 분석에서 그날 4개 구의 회수는 1,424대로, 다른 토요일 평균 769대의 약 1.9배였다.
- PRD는 이 상황을 `station_suspended`(운영 기관의 대여·반납 일시 중지) 제약으로 표현하고, 시뮬레이터 기준 시나리오와 Harness 평가셋(불꽃축제 대여 중지)에 넣었다.

출처: PRD 1.5 행사, 6.4, 9.1 · ROLES 3절 2 평가셋

| 항목 | 2025 서울시 발표 내용 |
| --- | --- |
| 행사 | 2025 서울세계불꽃축제, 9월 27일(토), 여의도 한강공원 |
| 중단 대상 | 공공자전거 따릉이와 민간 업체 7곳의 개인형 이동장치·전기자전거 |

| 사전 폐쇄 | 한강버스 여의도 선착장 따릉이 대여소는 행사 시설 설치로 9월 23일(화)부터 임시 폐쇄 |
| 대상 대여소 목록 | 보도자료 첨부 PDF 「교통지원 대책 및 따릉이 대여소 임시 폐쇄 구간 안내」에 있음 (이 문서에는 아직 옮기지 않음) |

## 3. 함께 있었던 교통 통제 `[보조]`

| 항목 | 2025 서울시 발표 내용 |
| --- | --- |
| 여의동로 전면 통제 | 9월 27일 14시 ~ 22시, 마포대교 남단 ~ 63빌딩 앞 |
| 버스 우회 | 여의동로 경유 19개 노선 |
| 한강대교 버스 무정차 | 9월 27일 16시 ~ 21시, 15개 노선 |
| 지하철 | 혼잡 시 5호선 여의나루역 무정차 통과, 출입구 폐쇄 가능 |

재배치 트럭도 통제 구간에 들어갈 수 없으므로, 해당 구간 대여소는 `station_blocked`(진입 불가) 대상이 될 수 있다 (팀 해석).

출처: 보조: 서울시 보도자료 (news.seoul.go.kr 530468)

## 4. 운영 기준에 따른 처리

1. 관리자가 "여의도 불꽃축제로 대여·반납 일시 중지"처럼 자연어로 입력하면 Agent가 제약 조건으로 바꾸고, 관리자가 확인한 뒤 계획을 다시 만든다.
2. 중지 기간 동안 해당 대여소의 수요는 0으로 보고 **배치 대상에서 뺀다.**
3. **사전 회수 여부는 관리자가 정한다.** 역산에서 당일 회수가 평소의 약 1.9배였던 것은 중지 전후로 자전거를 거둬들였기 때문으로 보인다 (팀 해석).
4. 중지 기간은 행사 시간(14~22시)보다 훨씬 넓다(전날 19시 ~ 다음 날 09시). 제약의 유효 기간은 행사 시간이 아니라 **공지된 중단 시간**으로 잡는다 `[보조]`.

출처: PRD 2.1 S1, 6.4, FR-09 · 보조: 서울시 보도자료

## 5. 제약 조건 예시

```json
{
  "type": "station_suspended",
  "station_ids": ["<첨부 PDF의 폐쇄 대여소 ID>"],
  "valid_from": "2025-09-26T19:00:00+09:00",
  "valid_to": "2025-09-28T09:00:00+09:00",
  "source": "manager",
  "reason": "2025 서울세계불꽃축제, 서울시 공유자전거 대여·반납 중단 공지 (여의도·마포·용산·동작)"
}
```

`station_ids`는 첨부 PDF의 대여소 목록을 대여소 마스터와 맞춰 채운다. 목록을 채우기 전에는 이 예시를 실제 시뮬레이션에 쓰지 않는다.

출처: PRD 6.4 Constraint 형식 · 보조: 서울시 보도자료

## 6. 확인이 더 필요한 것

- 첨부 PDF의 폐쇄 대여소 목록 (대여소 ID와 맞추기)
- 저장소의 "4개 구"가 보도자료의 여의도(영등포구)·마포·용산·동작과 같은지 (분석 담당 확인)
- 중단 시간(26일 19시 ~ 28일 09시)을 시뮬레이터 시나리오에 그대로 반영했는지
