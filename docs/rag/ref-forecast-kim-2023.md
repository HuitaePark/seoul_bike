# 공유자전거 따릉이 재배치를 위한 실시간 수요예측 모델 연구 (요약)

> 이 문서는 팀이 작성한 **요약**이다. 원문 문장을 옮기지 않았고, 수치는 원문 페이지와 대조했다.
> 다른 근거 문서(운영 기준, 역산 분석, 서울시 공지)는 팀 저장소를 기본으로 하고 이 논문을 `[보조]` 근거로 인용한다. 저장소 내용과 다르면 **저장소(PRD)가 우선**이다.
> "논문 내용"과 "팀 해석"을 절로 나눴다. 답변에 인용할 때는 둘을 구분한다.

## 1. 서지 정보

김유신(에어딥), 인터넷정보학회논문지 24권 5호 107~120쪽, 2023년 10월 31일 출판. DOI 10.7472/jksii.2023.24.5.107. 우리 PRD 14장 출처 목록에 이미 있는 논문이다.

## 2. 연구 개요 (논문 내용)

서울 따릉이의 대여소별 자전거 부족 문제를 다룬다. 대여·반납 이력과 날씨 데이터로 기계학습 모델을 만들어 대여소별 수요를 예측하고, 그 예측으로 재배치 수량을 산정해 서울시설공단 앱에 시범 적용했다. **경로 최적화는 다루지 않았고**, 재배치 우선순위와 최적 경로 추천을 향후 과제로 남겼다.

## 3. 데이터 (논문 내용)

- 2019년 1년치 대여소별 거치 현황·대여·반납 이력. 검증은 2019년 10월 한 달.
- 서울시설공단에서 직접 받은 데이터다. **공개데이터에는 대여소 재고 이력이 없으므로** 같은 방식으로 재현할 수 없다. 우리 PRD는 이 공백을 대여이력 역산(PRD 1.5)으로 메운다.
- 분석 기준 시점(2019-12-10)의 대여소 수는 1,540곳이다.

## 4. 예측 방식 (논문 내용)

| 항목 | 2019년 데이터 기준 논문 값 |
| --- | --- |
| 예측 단위 | 대여소 단위, 1시간 단위 |
| 예측 시점 | 매시간, 그 시점의 실제 재고와 최신 기상 예보를 반영해 다시 예측 |
| 예측 구간 | 예측 시점으로부터 3~5시간 뒤까지 (본문 기준) |
| 재학습 주기 | 매일 자정, 최근 90일 데이터로 재학습 |

## 5. 예측 정확도 (논문 내용)

| 항목 | 2019년 10월 검증, 1,540곳 기준 논문 값 |
| --- | --- |
| 대여 예측 RMSE | 2.336 (대여소·1시간당 약 2대 차이) |
| 반납 예측 RMSE | 2.343 (대여소·1시간당 약 2대 차이) |
| 오차가 큰 곳 | 거치대와 수요가 큰 대여소 (예: 여의나루역, 뚝섬유원지역) |

RMSE는 **1시간 구간 기준**이다. 3시간 이상 뒤의 오차는 논문에 따로 제시되지 않았다.

## 6. 운영 지표와 규모 (논문 내용)

| 항목 | 2019년 기준 논문 값 |
| --- | --- |
| 안전재고 목표 | 대여소별 적정 거치율 60% |
| 무재고시간(BST) | 피크 시간대 주 42시간 중 평균 2.45시간 (1,537곳) |
| 무재고시간 상·하위 | 상위 30곳 0.24시간, 하위 30곳 8.82시간 |
| 재배치 인력 | 배송 직원 136명 |
| 배송센터 | 11곳 (강북 5, 강남 6) |
| 재배치 범위 | 관할 구역 안에서만 재배치하며 교통·경로는 반영하지 못함 |

## 7. 인용 시 주의 (논문 내용 확인 결과)

- **데이터가 2019년이다.** 대여소 수와 이용 규모가 지금과 다르므로 "참고 기준"으로만 인용하고, 우리 시뮬레이터 결과와 같은 표에서 직접 비교하지 않는다.
- **논문 안 수치가 서로 다르다.** 대여소 수는 서론(2023년 약 2,700곳)과 결론(2023년 10월 약 4,700곳)이 다르고, 예측 구간은 본문 3~5시간과 앱 적용 절 3~6시간이 다르며, 하위 30곳 무재고시간은 본문 8.82시간과 결론 약 9시간이 다르다. **인용할 때는 본문 값(1,540곳, 3~5시간, 8.82시간)을 쓴다.**
- 무재고시간 평균의 모집단은 1,537곳으로, 대여소 수 1,540곳과 3곳 차이가 있다.

## 8. 우리 설계와의 연결 (팀 해석)

| 논문 내용 | 우리 설계에 주는 의미 | PRD 위치 |
| --- | --- | --- |
| 매시간 실재고·최신 예보로 재예측 | 오전 데이터로 오후를 계획하지 않고 롤링으로 갱신하는 근거. 예측 도구는 발행 시각(`issued_at`)을 함께 돌려준다 | 6.5, 7.1 |
| 3~5시간 앞 예측 | 예측 구간 `H = 3시간` 초기값의 근거. 5시간을 넘는 요청은 근거 밖이다 | 7.1 |
| 매일 자정 90일 재학습 | 예측 모델 갱신 주기의 근거 | 7.3 |
| RMSE 약 2대 | 재계산 임계값(재고 차이·도착 예상 2~3대)의 근거 | 6.3, 6.5 |
| 큰 대여소일수록 오차가 큼 | 우선순위가 높은 곳일수록 예측이 덜 정확하므로, 안전 여유를 대여소 규모에 따라 키운다 | 7.1 |
| 안전재고 60% | 목표 재고의 비교 기준. 단, 역산 결과(회수 직전 재고 중앙값 31대, 거치대 중앙값 10개)와 충돌하므로 실시간 수집(M1)으로 검증한다 | 7.1, 13 |
| 무재고시간 | PRD 주 지표 "빈 대여소-분"과 같은 개념. 발표 때 참고 기준으로 인용 | 9.2 |
| 배송 인력 136명·센터 11곳 | 시뮬레이터의 인력·차고지 규모 가정 | 1.5, 9.1 |
| 관할 구역 안에서만, 경로 미반영 | 문제 정의의 직접 근거. 우리 프로젝트가 채우는 빈칸(경로 최적화) | 1.1 |

## 9. 추론 (논문에 없는 팀 판단)

- RMSE가 1시간 기준이므로 "2대"는 **가까운 정류장 기준값**이다. 트럭이 늦게 도착하는 정류장일수록 오차가 커지므로, 도착 예정 시각이 멀수록 재계산 임계값과 안전 여유를 키우는 규칙이 필요하다. 이 규칙의 계수는 시뮬레이터로 정한다.
