# 따릉이 재배치 역산 분석 요약 (2025 대여이력)

> 원 분석 문서 「따릉이 재배치 역산 정리」는 저장소에 없다. 이 요약은 **저장소 PRD 1.5·7·8·12·13절에 옮겨진 내용**을 기본으로 했다.
> **모든 값은 추정이다.** 공개데이터에 재배치 기록이 없어 대여이력에서 거꾸로 추정했고, 실제 재고·운영과 대조하지 않았다.
> `[보조]`는 저장소 밖 자료에서 온 내용이다.

## 1. 왜 역산했나

공개데이터(서울 열린데이터광장)에는 재배치 기록도, 대여소 재고 이력도 없다. 그래서 2025년 대여이력에서 "어떤 자전거가 반납된 곳과 다음에 대여된 곳이 다르면 트럭이 옮긴 것"으로 보고 현행 재배치 운영을 추정했다. 이 추정은 시뮬레이터의 **현행 운영 재현 정책**의 입력이 된다.

- `[보조]` 2019년 연구는 서울시설공단에서 직접 받은 대여소별 거치 현황 이력을 썼다. 공개데이터로는 같은 방식을 재현할 수 없어서 우리는 역산을 쓴다. 발표 때 이 차이를 구분해서 설명한다.

출처: PRD 1.5, 8, 9.1 · 보조: ref-forecast-kim-2023 3절

## 2. 역산 기준 (임시값)

| 기준 | 값 |
| --- | --- |
| 이동 거리 | 150m ~ 10km |
| 다음 대여까지 시간 | 72시간 이내 |
| 하루 판정 폭 | ±2대 |
| 주말 비중 | 33% |

기준값은 임시값이다. 바꾸면 추정 수치도 달라지므로 **기준값별 민감도를 함께 기록한다.** 고장신고 데이터로 정비 이동을 빼지만, 현장 판단 수거가 신고의 약 2배라는 보도(헤럴드경제)가 있어 정비 수거를 다 걸러내지 못할 수 있다.

출처: PRD 8 데이터 한계, 8 데이터 표

## 3. 핵심 추정값 (2025년)

| 항목 | 2025 역산 추정값 |
| --- | --- |
| 하루 재배치량 | 성수기(4~10월) 약 4,100~4,900대, 12~2월 약 1,700~1,900대 |
| 트럭 용량 | 약 15대 (방문 묶음이 13~15대에 몰리고 15대를 넘으면 급감) |
| 근무 시간대 | 07–10시, 13–16시, 19–20시. 밤(22~06시) 확실한 방문은 약 2% |
| 배치 직전 재고 | 중앙값 2대, 30%가 0대 |
| 회수 직전 재고 | 중앙값 31대 (거치대 중앙값 10개) |
| 대여소 역할 | 회수 533곳, 배치 531곳 (각 19%) |
| 역할의 일관성 | 하루 불균형 10대 이상 182곳은 87%의 날 같은 방향, 3대 미만 1,248곳은 51% |
| 고도 | 자치구 중앙값보다 30m 이상 높은 대여소 중 배치 대여소 비율 57%. 재배치는 자전거를 평균 14.4m 위로 옮김 |
| 공급처 분산 | 상위 배치 대여소에서 가장 많이 가져온 한 곳의 비중 9~35% |
| 행사 | 2025 불꽃축제 당일 4개 구 회수 1,424대 (다른 토요일 평균 769대의 약 1.9배) |

출처: PRD 1.5

## 4. 설계에 반영한 내용

| 추정값 | 설계 반영 |
| --- | --- |
| 하루 재배치량 | 시뮬레이터 규모, 현행 운영 재현 |
| 트럭 용량 15대 | 경로 최적화 적재량 상한 초기값 (PRD 7.2) |
| 근무 시간대 | 근무조 3개와 계획 초안 생성 시각 (PRD 7.4) |
| 방문 직전 재고 | 목표 재고 범위, 빈 대여소·과적재 지표 (PRD 7.1, 9.2) |
| 회수 533곳·배치 531곳 | 고정 회수·고정 배치 역할을 사전 정보로 사용 (PRD 7.1) |
| 3대 미만 1,248곳은 방향이 51% | 역할로 대체할 수 없으므로 **예측 노력을 이 대여소들에 집중** (PRD 7.3) |
| 고도 | 예측 피처, 설명 문장 (PRD 7.3) |
| 공급처 분산 9~35% | 고정 짝짓기 대신 VRP(경로 최적화)를 쓰는 근거 |
| 불꽃축제 1,424대 | `station_suspended` 제약, 시뮬레이터 기준 시나리오 (PRD 6.4, 9.1) |

출처: PRD 1.5, 7.1, 7.3

## 5. 가장 중요한 설계 영향: 만차의 정의

회수 직전 재고 중앙값(31대)이 거치대 중앙값(10개)의 약 3배라면, 거치대가 다 찬 상태가 반납을 막는 것은 아니다. 그래서 PRD는 **거치대 수를 재고의 하드 상한으로 쓰지 않고**, 빈 대여소와 과적재를 별도 지표로 다룬다. 운영 상한은 설정값이며 초기값은 거치대 수다.

- `[보조]` 2019년 연구는 거치대의 60%를 안전재고 목표로 썼다. 역산 결과(거치대의 약 3배까지 쌓임)와 크게 다르므로, 어느 쪽이 현실에 가까운지 실시간 수집으로 확인해야 한다.

출처: PRD 1.5 설계 영향, 7.1, 9.2 · 보조: ref-forecast-kim-2023 6절

## 6. 한계

- **추정량은 하한에 가까울 수 있다.** 72시간 안에 다시 대여되지 않거나 여러 번 옮겨진 자전거는 빠지거나 한 번으로 합쳐진다.
- 근무 시간대는 시각이 1시간 안으로 좁혀지는 방문만으로 추정해 밤 작업이 적게 잡혔을 수 있다.
- '반납 − 대여'와 트럭 순반출의 상관(0.999)은 자전거 수 보존에서 나오는 항등 관계에 가깝다. 대여소를 고르는 방법으로만 쓰고 **검증 근거로 쓰지 않는다.**
- 빈 대여소에서는 대여 자체가 기록되지 않아 수요가 **과소 추정**된다. 배치 직전 30%가 0대였으므로, 재고 0인 시간대는 학습에서 빼거나 인접 시간대·유사 대여소로 보정한다.

출처: PRD 8 데이터 한계, 7.3, 7.4, 12

## 7. 검증 계획

- **첫날부터** 서울 열린데이터 실시간 대여정보를 5~10분 간격으로 수집한다 (6 데이터 분석·시뮬레이터 담당).
- 역산 재고(배치 직전 2대, 회수 직전 31대)를 실시간 값과 대조해 운영 상한(만차 정의)을 정하고, 역산 기준값의 민감도를 기록한다.
- 인터뷰로 확인할 항목: 트럭 용량 15대가 용량인지 운영 규칙인지, 거치대 수를 넘어 반납할 수 있는지, 근무조가 세 개인지와 밤 작업 여부.

출처: ROLES 2.2 M0·M2, 3절 6, PRD 11 M1, 13
